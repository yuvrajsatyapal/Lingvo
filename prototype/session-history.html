Prototype notes

  • A session = one Start → Stop. The engine already tags every saved line with a sessionId, so the list is a grouping, no new capture logic.
  • List is grouped by day, newest first. The running session is pinned on top and updates live.
  • Detail replays the session as a timeline with timestamps. Toggle between translation + original, translation only, or original only.
  • Search works on the list (title, text) and inside a session (highlights matches).
  • Per-session Copy, Save as text and Delete. Clear-all stays available in the list footer.
  • Titles are auto-generated from the first line. Rename is a later step.
Needs backend later: session list query (start/end time, line count, langs), per-session delete, session title.
